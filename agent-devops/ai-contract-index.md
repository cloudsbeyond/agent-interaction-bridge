# AI Contract Index

Within Agent DevOps, this index links Build-Agent-authored L4 artifacts back to
upstream L1/L2 contracts. Update it whenever the Build Agent changes generated
code, contract-maintained code, generated pages, SDKs, DTOs, indexes,
presentation outputs, ontology objects, SOPs, or framework boundary code.

All repository implementation is treated as Build-Agent-authored unless an
index row says otherwise. `Status` records contract coverage, not authorship.

Human corrections should change an upstream contract, harness, or local durable
contract first. Implementation code is then changed by the Build Agent under
that updated evidence.

## State Semantics

- L0-L2 uses `frozen` or `draft`.
- L3-L4 uses `covered`, `partial`, or `draft`.
- `frozen` means the L0-L2 contract is the current architecture source.
- `covered` means the current artifact has harness evidence for the stated
  responsibility.
- `partial` means the artifact belongs in the current scope but still has a
  named gap.
- `draft` means the contract or artifact is not durable.
