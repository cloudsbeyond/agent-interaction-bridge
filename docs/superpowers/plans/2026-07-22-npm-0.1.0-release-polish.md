# npm 0.1.0 Release Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish three bounded operator-experience fixes and produce complete local evidence for the first `agent-interaction-bridge@0.1.0` npm release without publishing it.

**Architecture:** Normalize only strict single-command fenced messages at Feishu intake, lower task approvals through the existing managed CardKit path, and wait for LaunchAgent readiness from launchd plus registry health facts. Keep approval authority in the existing store and keep npm publication human-owned.

**Tech Stack:** TypeScript, Node.js 20+, Vitest, pnpm, tsup, Feishu/Lark Node SDK, macOS launchd, npm.

## Global Constraints

- Keep `README.md` and `PRD.md` product intent unchanged.
- Keep package version `0.1.0` unless the npm registry proves that exact version already exists.
- Add no runtime dependency and no generic service supervisor or markup parser.
- Card update failure must not reverse or block a validated approval decision.
- Only one whole-message fenced slash-command line may be normalized.
- Stop before `npm publish`, git tag creation, repository visibility changes, or credential changes.

- [ ] **Step 3: Implement the strict normalizer**

Use one anchored expression and preserve the original input on every rejected shape:

```ts
export function normalizeFeishuCommandContent(content: string): string {
  const trimmed = content.trim();
  const match = /^```(?:(plain_text|plaintext|text))?[ \t]*\r?\n([\s\S]*?)\r?\n```$/i.exec(trimmed);
  if (!match) return content;
  const lines = (match[2] ?? '').split(/\r?\n/).map((line) => line.trim()).filter(Boolean);
  return lines.length === 1 && lines[0]?.startsWith('/') ? lines[0] : content;
}
```

async function settleApprovalCard(
  channel: LarkChannel,
  messageId: string,
  approval: PendingApproval,
  action: ApprovalDecisionAction,

  if (!isManaged(messageId)) return;

  }
}
